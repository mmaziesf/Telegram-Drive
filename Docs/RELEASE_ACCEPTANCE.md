# Release acceptance: owner checklist

For desktop 4.0.0, every manual platform, installed-upgrade, real WebView, and live Telegram acceptance row below is **not run for 4.0.0 by owner decision**. These rows are not passed by local fixtures or automated CI. Automated builds and suites still must pass. No manual platform or live-service exercise is authorized in this release cycle.

The steps below remain a future acceptance runbook. Record source revision, installed version, OS/device/WebView, exact artifact/checksum/signature, date and sanitized evidence if a later owner decision authorizes them. Never expose sessions, API hashes, recovery codes or private keys. TDENC2 remains frozen-format beta with independent cryptographic review pending. Desktop 4.0.0 and Android/Google TV 4.1.0 preview are independent version lines; no Android build or release occurs here.
